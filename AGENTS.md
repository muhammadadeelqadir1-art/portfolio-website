# AGENTS.md

## Project Context

This project is a portfolio website built by recreating a design selected in Figma.

## Workflow

1. **Figma design selected** — A design has been chosen in Figma.
2. **Connect with Figma Bridge MCP** — Use the Figma Bridge MCP server to access the design.
   - First install the Figma Bridge MCP for the agent so it can access the design files.
3. **Recreate the design exactly** — Build the design using:
   - HTML
   - CSS
   - JavaScript
   - Keep files separated (separate HTML, CSS, and JS files).
   - Recreate the design exactly as it appears in Figma.
4. **Add interactions** — After the static design is complete, add interactions and animations.
5. **Add additional elements** — Extend the design with any required supplementary elements.

## Important Notes

- The agent must install/configure the Figma Bridge MCP before accessing the design.
- Separate HTML, CSS, and JS files should be maintained (no single-file solutions).
- Pixel-accurate recreation of the Figma design is the priority before adding interactions.
